# Enhanced Buddy Code Editor 🚀

## Overview

The Enhanced Buddy Code Editor is a powerful, feature-rich code editor built into the Buddy app, designed to provide an Acode-like experience with advanced functionality for mobile and desktop development.

## ✨ Key Features

### 🎨 Advanced Text Editor
- **Syntax Highlighting**: Multi-language support with customizable themes
- **Auto-completion**: Intelligent code suggestions based on language context
- **Multi-cursor Support**: Edit multiple locations simultaneously
- **Undo/Redo**: Comprehensive history management with 100-level deep history
- **Line Numbers**: Optional line number display with selection highlighting
- **Word Wrap**: Smart text wrapping for better readability

### 📁 Advanced File Management
- **File Tree**: Hierarchical project structure with expand/collapse
- **Context Menus**: Right-click operations (rename, delete, create)
- **File Icons**: Language-specific icons for easy identification
- **Multi-tab Support**: Work with multiple files simultaneously
- **Unsaved Changes Indicator**: Visual feedback for modified files
- **Auto-save**: Configurable automatic file saving

### 🔍 Powerful Search & Replace
- **Find & Replace**: Advanced search with multiple options
- **Regular Expressions**: Full regex support for complex patterns
- **Case Sensitivity**: Toggle case-sensitive search
- **Whole Word**: Match complete words only
- **Search Results**: Visual indicators for match count and navigation

### 🛠 Developer Tools
- **Integrated Terminal**: Full terminal access within the editor
- **Command Palette**: Quick access to all editor functions
- **Code Formatting**: Language-specific code formatting
- **Comment Toggle**: Quickly comment/uncomment code blocks
- **Git Integration**: Built-in version control support

### 🔌 Plugin System
- **Extensible Architecture**: Modular plugin system
- **Built-in Plugins**: Essential plugins included out of the box
- **Custom Commands**: Define custom editor commands
- **Sidebar Panels**: Plugin-contributed UI panels
- **Event System**: Plugin communication through events

## 🚀 Getting Started

### Opening the Editor
1. Navigate to the **Flow** tab in Buddy
2. Tap on **Code Editor** or use the floating action button
3. Create a new project or open an existing one

### Creating a Project
1. Click **New Project** in the toolbar
2. Choose from available templates:
   - Flutter Application
   - Python Application
   - Node.js Application
   - Android Native App
3. Configure project settings
4. Start coding!

### Working with Files
1. Use the file tree to navigate your project
2. Click files to open them in new tabs
3. Right-click for context menu options
4. Drag tabs to reorder them
